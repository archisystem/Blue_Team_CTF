# CyberDefenders --- GrabThePhisher

Учебный разбор лаборатории **GrabThePhisher** с платформы
CyberDefenders. Работа посвящена анализу фишингового набора, поиску
артефактов, изучению способа передачи похищенных данных и основам Threat
Intelligence в рамках Blue Team.

## Цели

-   Изучить структуру фишингового набора.
-   Определить используемый кошелёк и язык программирования.
-   Найти код обработки данных и журнал записей.
-   Выявить канал передачи данных.
-   Понять, как извлекать индикаторы компрометации (IOC) из файлов.
-   Сформулировать выводы и рекомендации для Blue Team / SOC.

## Лаборатория

-   **Платформа:**
    [CyberDefenders](https://cyberdefenders.org/blueteam-ctf-challenges/grabthephisher/)
-   **Категория:** Blue Team / Threat Intelligence
-   **Уровень:** Easy (по карточке лаборатории)
-   **Основные темы:** фишинг, PHP, журналы, IOC, Telegram Bot API,
    расследование инцидентов.

## Полезные команды

Найти PHP-файлы:

``` bash
find . -type f -name "*.php"
```

Найти HTML-файлы:

``` bash
find . -type f -name "*.html"
```

Найти журнал:

``` bash
find . -type f -name "log.txt"
```

Искать ключевые строки в PHP-коде:

``` bash
grep -RinE "metamask|wallet|phrase|seed" .
grep -RinE "telegram|api.telegram.org|sendMessage" .
grep -RinE "sypexgeo|geo|ip-api|ipinfo" .
```

Просмотреть файл с номерами строк:

``` bash
nl -ba <путь_к_файлу.php> | less
```

## Выводы

Фишинговый набор имитирует запрос seed-фразы криптовалютного кошелька.
Анализ HTML, PHP-кода и журналов помогает определить используемые
технологии и способ передачи данных. Для расследования инцидента важно
сохранять исходные артефакты, документировать индикаторы, проверять их
по независимым источникам и не делать выводов о личности оператора
только по имени или username.

## Рекомендации Blue Team

-   Проверять журналы DNS, прокси, EDR и сетевых средств на
    подозрительные обращения.
-   Искать индикаторы фишинга и подтверждать их перед блокировкой.
-   Рассматривать обнаруженные токены как потенциально
    скомпрометированные секреты.
-   Не публиковать seed-фразы, токены, пароли и другие секретные данные.
-   При подтверждённой компрометации кошелька безопасно перенести активы
    в новый кошелёк с новой seed-фразой.
